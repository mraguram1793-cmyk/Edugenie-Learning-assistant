## 🏛️ Architecture Overview

> *(See [`Solution_Architecture.pdf`](./Solution_Architecture.pdf) for the full diagram)*

The EduGenie architecture encompasses:

- **AI/ML Layer** — LLM inference and personalization engine
- **Backend Services** — API handling, user management, and data processing
- **Frontend Interface** — Learner-facing application
- **Data Storage** — User profiles, learning history, and content repositories
- **Cloud Infrastructure** — Scalable deployment environment
