## 🧠 About the Project

**EduGenie** is a Generative AI-powered educational assistant that adapts to each learner's needs. It leverages Large Language Models (LLMs) and AI/ML techniques to deliver personalized content, assessments, and feedback — making quality education accessible to everyone.

The project was developed as part of the **AI/ML & Generative AI Track** and follows a structured software development lifecycle from ideation to demonstration.

---

## 🔄 Project Lifecycle

This repository is organized by project phases:

| Phase | Description |
|-------|-------------|
| **1. Brainstorming & Ideation** | Problem statement definition, empathy mapping, and idea prioritization |
| **2. Requirement Analysis** | Solution requirements, customer journey map, data flow diagrams, and technology stack |

## 🚀 Getting Started

> *(Refer to [`Project_Executable_Files.pdf`](./7.Project%20Documentation/Project_Executable_Files.pdf) for detailed setup and execution instructions)*

### Prerequisites

- Python 3.9+
- pip / conda
- API keys for LLM services (if applicable)

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/AI_ML-and-Gen-AI-Track-Project-template-.git
cd AI_ML-and-Gen-AI-Track-Project-template-

# Install dependencies
pip install -r requirements.txt

# Run the application
python main.py
```
