# 📋 Phase 2: Requirement Analysis

> This phase translates brainstormed ideas into concrete requirements — detailing the solution scope, user journeys, data flows, and technology choices for **EduGenie**.

## 📂 Contents

| File | Description |
|------|-------------|

---

## 🎯 Phase Objectives

- **Define Requirements** — Specify what the system must do (functional) and how well it must perform (non-functional)
- **Map the User Journey** — Visualize the complete learner experience across all touchpoints
- **Model Data Flows** — Understand how data is generated, processed, and consumed
- **Finalize Tech Stack** — Select the right technologies to build the solution

---

## 🔍 Key Outcomes

- ✅ Comprehensive solution requirements document
- ✅ Customer journey map illustrating the EduGenie user experience
- ✅ Data flow diagram showing system inputs, processing, and outputs
- ✅ Justified technology stack selection

## 🛠️ Technology Highlights

- Python-based ML pipeline

- Modern frontend for learner interaction
